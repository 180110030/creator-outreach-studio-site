Privacy & Data Practices

Last updated: October 2026

Project status

Creator Outreach Studio is an independently developed, locally tested prototype. This page describes its intended and current local usage at a high level; it is not a representation of an externally hosted user service.

Information considered

The prototype uses the YouTube Data API Services to retrieve publicly available video and channel information for creator discovery. The local application may also organize publicly displayed business contact details, review notes, and records of outreach initiated by the operator.

Purpose

Information is used to identify potentially relevant creators, assess content suitability for proposed brand collaborations, and organize manual review and outreach workflows. Creator records are not presented as authoritative audience-demographic data.

Local storage and access

The application is currently operated in a local development environment. Data access depends on the developer's local machine and application configuration. There is currently no public account registration through this website. The public pages themselves do not include any creator database, API credentials, or individual outreach records.

YouTube API data

YouTube API-derived information remains subject to YouTube API Services Terms of Service and Developer Policies. Data accuracy and freshness can change. Before external release, the developer must verify that the application's actual caching, refresh, deletion and data-rights processes comply with those policies; this page does not claim that every future configuration has been approved by YouTube.

Sharing

This informational website does not provide third-party access to the local creator database. The developer may provide project documentation and demonstrations to Google for an applicable API audit. No public self-service export or sale of creator records is offered through this website.

Security

API keys and mail credentials must not be included in public site source files. Do not submit sensitive credentials through this website; it has no account or contact form.

Contact and inquiries

For privacy-related questions, use the developer contact information provided in the corresponding Google API audit submission. A dedicated public contact address can be added once configured.

Changes

This notice should be reviewed and updated before deployment of an online, multi-user, or commercial edition, particularly if data flows, retention, user access, or third-party processors change.
