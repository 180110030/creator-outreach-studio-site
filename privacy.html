Privacy Policy & Data Practices

Last updated: 27 October 2026

Scope: This policy describes a privately operated, locally hosted development prototype and its public informational website. The application is not available for public registration or remote use at present. It is not a statement that the software has been approved by Google or YouTube.

1. Data sources and categories

During local testing, the application accesses the YouTube Data API Services to search publicly available videos and retrieve relevant public video and channel metadata (such as video titles, descriptions, channel identifiers, publicly visible statistics, and channel descriptions). The operator may also record publicly displayed business contact details, manual assessment notes, outreach statuses, and business correspondence records. We do not claim to obtain private YouTube account data or verified audience demographics.

2. Purposes

Data are used to discover potential creator partners, assess whether their public content is relevant to proposed brand/product collaborations, avoid duplicate outreach, manage manually reviewed contact records, and monitor the application's API usage during testing. No public directory of the locally collected creator records is provided on this website.

3. Data processing and local access

Operational records are stored within the local application environment, currently including a local database. The developer controls access to the computer and application. The public GitHub Pages site contains only informational documents; it does not collect form submissions, accept user registrations or display operational creator records. As a GitHub Pages-hosted website, ordinary requests may be processed by GitHub under its own policies.

4. YouTube API data freshness, retention and deletion

YouTube-derived API Data are subject to the YouTube API Services Terms of Service and Developer Policies, including applicable requirements to refresh, delete or stop using data when required. The current prototype maintains local search and candidate records; its automatic refresh, retention-limit enforcement and deletion-request workflow have not yet been fully verified as compliant. This notice does not claim an implemented 30-day automated purge or any special storage extension approval.

Before broader use or additional production-scale retention, the developer intends to audit these processes and implement applicable data lifecycle controls. Relevant YouTube API-derived data may need to be refreshed or removed in accordance with YouTube policy, regardless of whether the prototype is publicly released. Pending this review, this prototype should not be treated as a production-compliant data archive.

5. Derived assessments

The prototype may display locally calculated relevance or performance assessments based on public content and API-derived metrics. These are internal screening aids, not official YouTube ratings, and are subject to YouTube's restrictions on derived metrics. No additional YouTube permissions or exemptions are represented as already granted.

6. Sharing and disclosure

The developer does not publicly sell or publish the local creator database through this website. Relevant application documentation and redacted screenshots or recordings may be provided to Google for the API compliance and quota-extension review. Any future team collaboration, hosting, or third-party service integrations would require this policy to be reviewed and updated.

7. Security

API keys, SMTP passwords and private databases are not included in this public website. Do not submit credentials or personal information to this informational website; it has no account or contact form. Local access controls and backup practices are managed by the developer and remain under review before wider deployment.

8. Questions, correction and deletion requests

For questions concerning the application's handling of creator information, including correction or deletion requests, the reviewer may use the developer's contact email submitted in the Google API audit form. A public, dedicated contact address has not yet been configured. This is a current limitation and should be addressed before public release or use at scale.

9. Third-party terms and privacy

The application uses YouTube API Services and must adhere to the YouTube API Services Terms of Service and YouTube API Services Developer Policies. See also the Google Privacy Policy. This informational website is hosted by GitHub Pages; please refer to GitHub's privacy statement for GitHub's handling of web traffic.

10. Updates

This notice will need revision when the application moves beyond personal testing, introduces public accounts, changes data retention processes, or adopts cloud-based data storage.
