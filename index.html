Creator Outreach Studio is a locally operated software prototype for researching public creator content, reviewing potential brand partnership candidates, and organizing outreach workflows.

Private development & testing · Not publicly accessible

Current prototype capabilities

Public video discovery

Uses the YouTube Data API Services to search publicly available videos and identify their publishing channels.

Multiple discovery paths

Supports keyword, topic-based, competitor-related and product-use-case research plans.

Human-led qualification

Supports review of content relevance and publicly displayed business contact information before outreach.

Local workflow tracking

Maintains candidate records, review statuses, outreach history and locally tracked API search activity.

YouTube data use and independence

The application uses YouTube Data API Services to retrieve public search results and relevant video/channel metadata. The developer uses this information to assist manual research and assessment of potential creator partnerships. The project does not access creators' private accounts or obtain audience demographics through the YouTube Data API.

Independent application: Creator Outreach Studio is not affiliated with, sponsored, certified or endorsed by YouTube or Google. YouTube is a trademark of Google LLC. Visit YouTube and read the YouTube API Services Terms of Service.

Application access

Local prototype — not a hosted login portal.

The interactive application runs locally on the developer's computer. This public website is informational only; it does not provide a demo account, expose the creator database, or execute YouTube API requests. Application screenshots and a local workflow demonstration may be provided separately to reviewers.

Privacy and documentation

For details about the prototype's data use, retention limitations and rights requests, read the Privacy Policy. Review the current Terms of Use for the private testing project.

Project contact
